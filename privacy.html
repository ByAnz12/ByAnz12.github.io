Kebijakan Privasi

Berlaku sejak 31 Oktober 2026. Kembali ke Titeni Yt Smart

Siapa yang memakai aplikasi ini

Titeni Yt Smart adalah aplikasi desktop pribadi yang dipakai pemilik channel ABIZAR GAMING di komputernya sendiri. Aplikasi ini tidak punya server dan tidak melayani pengguna lain.

Data Google yang diakses

Setelah pemilik channel login dengan akun Google, aplikasi meminta tiga izin dan memakainya untuk:

  • youtube: membaca nama channel dan jumlah subscriber, membaca hasil pencarian video publik, serta mengatur thumbnail, metadata, dan playlist video milik channel.
  • youtube.upload: mengupload video ke channel pemiliknya sesuai mode yang dipilih pemilik channel.
  • yt-analytics.readonly: membaca statistik video channel untuk layar analisa.

Penyimpanan

Semua data disimpan di komputer pemilik channel. Refresh token dan kredensial klien dienkripsi dengan Windows DPAPI. Access token hanya berada di memori. Tidak ada data yang dikirim ke server pembuat aplikasi, karena server seperti itu tidak ada.

Pembagian data

Data tidak dijual dan tidak dipakai untuk iklan. Untuk menyusun usulan judul dan deskripsi, aplikasi mengirim bahan teks ke penyedia LLM yang dipilih pemilik channel: judul dan tag video publik dari hasil pencarian, transkrip suara, serta catatan video. Gambar dari rekaman bisa ikut dikirim dengan facecam ditutup bila fitur itu dinyalakan. Video dan audio tidak dikirim ke penyedia LLM. Refresh token dan kunci tidak pernah dikirim ke penyedia LLM.

Mencabut akses dan menghapus data

Pemilik channel bisa mencabut akses kapan saja di Izin Akun Google. Tombol Putuskan sambungan di aplikasi menghapus refresh token dari komputer. Data lain terhapus dengan menghapus folder data aplikasi dan folder kerjanya.
